# Personal website

## Add your files
- `assets/photo.jpg`: your headshot (portrait, roughly 5:6 ratio)
- `files/cv.pdf`: your CV
- `files/paper.pdf`: your paper

## Fill in the placeholders
Search `index.html` for `EDIT` and replace each `[bracketed]` item, including the
YouTube playlist URL and arXiv link.

## Publish on GitHub Pages
1. Create a repo named `<your-github-username>.github.io`.
2. Upload everything in this folder (index.html, style.css, assets/, files/).
3. In the repo: Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Your site will be live at `https://<your-github-username>.github.io` within a few minutes.
